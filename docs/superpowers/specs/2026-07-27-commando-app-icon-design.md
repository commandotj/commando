# Commando 应用图标设计

日期：2026-07-27  
状态：已批准，待实施

## 目标

为 Commando 文件夹同步工具制作高辨识度卡通应用图标。图标必须在 macOS Dock、Windows 任务栏和 32px 文件列表中仍能表达“两个文件夹双向同步”。

## 已选方向

名称：文件交接队  
风格：软陶 3D

蓝色与橙色文件夹拟人角色共同交接一张暖黄色文件。青绿色双向循环箭头包围主体，明确双向同步语义。表情使用小眼睛和克制微笑，友好但不幼稚。

## 视觉结构

画布为 1024×1024 正方形。主体位于中央 70% 区域，四周保留至少 15% 安全边距。

左侧蓝色文件夹与右侧橙色文件夹略微内倾。交接文件位于视觉中心，必须遮挡最少。循环箭头位于角色后方，不覆盖表情与交接文件。

背景使用低对比度冷白到浅蓝软渐变。主体使用圆润软陶材质、柔和棚拍光和清晰外轮廓。阴影只用于区分层次，不产生悬浮杂乱感。

## 色彩

- 左侧文件夹：天蓝到群青。
- 右侧文件夹：暖黄到橙色。
- 交接文件：奶油黄，少量珊瑚色线条。
- 循环箭头：青绿色。
- 背景：冷白与浅蓝。

色彩必须保持四个明确层级。禁止额外彩虹高光，避免现有候选图标的霓虹噪声。

## 约束

- 不使用文字、字母、品牌缩写或水印。
- 不使用玻璃、透明塑料或强霓虹效果。
- 不添加设备、云朵、闪电、齿轮等辅助符号。
- 不让角色手脚成为主要轮廓；文件夹本体保持一眼可辨。
- 双向箭头必须形成完整循环，避免被误读为单向发送。
- 32px 预览必须仍能辨认两个文件夹、中央文件和循环箭头。

## 生成与选择

先生成一张 1024×1024 候选图。首次生成只验证构图、角色轮廓、同步语义和材质，不扩展额外元素。

检查候选后最多进行一次针对性修订。修订只能处理一个主要问题，例如缩略图轮廓、箭头遮挡或表情过度，不同时改变整体方向。

## 非破坏落地

生成结果先保存为 `apps/desktop/build/appicon-c1.png`，不得直接覆盖现有 `apps/desktop/build/appicon.png`。

候选通过 1024px、128px、32px 预览检查后，才允许替换主图并重新生成 macOS、Windows 与 iOS 平台图标。平台图标替换属于后续独立实施步骤。

## 验收标准

1. 1024×1024 图像无文字、无水印、无裁切。
2. 蓝橙文件夹、中央文件、双向循环箭头四个核心元素清楚。
3. 软陶材质统一，无玻璃感和霓虹溢光。
4. 128px 预览保持清晰层次。
5. 32px 预览仍可识别为文件夹同步工具。
6. 新候选以版本化文件保存，不覆盖现有图标。
